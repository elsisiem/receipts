Add it to your agent.
receipts is also an MCP tool. Your agent calls it before it says “done”, learns which claims it can't back up, and fixes them first. Works in Claude Code, Cursor, Codex, Windsurf or any MCP client. No model keys needed.

    

      

        
Two tools your agent gets

        
receipts_run_and_check

        
Runs your tests (or any command), captures the real output, and checks the agent's “done” message against it.

        
receipts_check

        
Checks a message against a log you already have: a CI log, a terminal session.

        
What your agent sees (a real response)


receipts: 0 backed, 1 contradicted, 2 never ran.
- CONTRADICTED (100%) All 12 tests pass | log: "FAILED (failures=2)"
- NEVER RAN (99%) Added the parser | log: nothing
- NEVER RAN (100%) lint is clean | log: nothing
Fix or remove contradicted claims, and either verify or
soften never-ran claims, before reporting to the user.
